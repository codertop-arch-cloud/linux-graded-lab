2. FILE DESCRIPTOR INVESTIGATION
----------------------------------------------------------------------
Command Executed:
$ ls -l /proc/$$/fd

Expected Output:
ls: /proc/46236/fd: No such file or directory

Explanation of Command:
On Linux systems, '/proc/$$/fd' (where '$$' expands to the current shell PID) allows dynamic inspection of process file descriptors as symbolic links. Since this lab was executed on macOS (which does not implement a native '/proc' filesystem), the command returns a "No such file or directory" error, illustrating key differences between macOS and Linux process observation interfaces.

3. OUTPUT REDIRECT OPERATIONS (OVERWRITE)
----------------------------------------------------------------------
Command Executed:
$ echo "Hello Linux" > output.txt

Explanation of Command:
The 'echo' command prints its argument string. The '>' redirection operator redirects Standard Output (FD 1) to the file 'output.txt', overwriting any existing file content and writing the string "Hello Linux\n" directly to disk.

4. OUTPUT REDIRECT OPERATIONS (APPEND)
----------------------------------------------------------------------
Command Executed:
$ echo "Another line" >> output.txt

Explanation of Command:
The '>>' redirection operator redirects Standard Output (FD 1) to the file 'output.txt', appending the string "Another line\n" to the end of the file rather than overwriting its existing contents.

5. ERROR REDIRECT OPERATIONS
----------------------------------------------------------------------
Command Executed:
$ ls does_not_exist 2> error.txt

Explanation of Command:
The command 'ls does_not_exist' fails and generates an error message. The '2>' operator redirects Standard Error (FD 2) to 'error.txt', writing the error diagnostics to the file while keeping the terminal screen clean of error output.

9. CONCLUSIONS
----------------------------------------------------------------------
- Redirection operators are standard shell features that allow developers and admins to decouple command execution from terminal display, facilitating logging and data processing pipelines.
- Standard streams (stdin, stdout, stderr) are handled as numeric file descriptors (0, 1, 2) that can be redirected independently, as shown by capturing error logs separately from stdout.
- Resource constraints, like the open file descriptor limits shown by the ulimit command, are critical boundaries configured by the kernel to prevent system resource exhaustion.

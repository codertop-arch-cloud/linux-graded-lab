The 'df -i' command displays inode (index node) allocation and usage across filesystems. Inodes are metadata indexes representing files; a system can run out of inodes even if storage bytes are free. 6. RECOMMENDATIONS FOR IMPROVING STORAGE UTILIZATION
----------------------------------------------------------------------
To prepare for deploying the new application server, the following recommendations are provided to maintain storage health:

1. Configure Log Rotation (logrotate):
   Implement a system log rotation policy (e.g., daily or weekly compression and truncation) so that application and database logs do not consume disk space indefinitely.

2. Establish Disk Quotas:
   If multiple users or departments are sharing the server, set up disk quotas (using usrquota/grpquota mount options) to prevent a single user from consuming all available disk blocks.

3. Automated Cleanups:
   Schedule a daily cron job to scan and prune temporary files in the '/tmp' directory and clear expired cache files.

4. Monitoring and Alerts:
   Configure automated monitoring tools (like Prometheus Node Exporter or custom cron scripts) to send alerts when disk capacity exceeds 80% or when inode usage exceeds 85%, ensuring preemptive action can be taken.

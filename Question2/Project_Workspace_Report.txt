----------------------------------------------------------------------

Explanation of Command:
The 'umask' command displays the default system user mask, which determines the initial file permissions for newly created files and directories. A umask of 022 automatically strips write privileges for groups and others, resulting in 755 permissions for folders and 644 for files.

6. TECHNICAL OBSERVATIONS & DETAILED SECURITY ANALYSIS
----------------------------------------------------------------------
Permission Analysis Summary:
- Workspace Directory (Before: drwxr-xr-x / 755) -> (After: drwxr-x--- / 750)
- Project Document (Before: -rw-r--r-- / 644) -> (After: -rw-r----- / 640)
- Owner: aanshu1 (Full Read/Write access)
- Group: staff (Read-only/traverse access for directory; Read-only access for files)
- Others/World: No Access (Completely blocked)

Explanation of Security Protection:
- The owner 'aanshu1' retains full administrative control, allowing modifications, deletions, and standard file operations.
- The group 'staff' has read-only privileges, which is ideal for a collaborative team structure where members need to view documentation and run binaries/enter folders but cannot make unauthorized modifications.
- By stripping permissions from 'others' (the 0 in 750 and 640), we ensure that any unauthorized system users who are not part of the 'staff' group are completely blocked from viewing directory contents or accessing files. This implements the Principle of Least Privilege.

7. SYSTEM UMASK VALUE VERIFICATION
----------------------------------------------------------------------
Command Executed:

Expected Output:

Explanation of Command:
The 'umask' command prints the current shell user file-creation mask. A value of 022 specifies that newly created directories will default to 755 (rwxr-xr-x) and files to 644 (rw-r--r--), by masking out write permissions for groups and others.
